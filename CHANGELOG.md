# История изменений

## 4.0.3 — 2026-10-25

### Исправлено

- кнопка «Опросить» в списке и карточке возвращает на ту же страницу с фильтрами,
  а не открывает обзор устройства;
- «Обновить» на вкладке свойств действительно ставит запрос состояния в очередь,
  а не просто перезагружает страницу;
- после partLoad возврат не содержит служебный `part_load`;
- справка по модели переводится в карточки `MDJUI`: таблицы `md-table`, без
  Bootstrap-панелей и inline-ширины 800 px; на телефоне таблица прокручивается,
  а не сжимается в нечитаемые колонки;
- поиск по названию, IP и модели снова работает: `%` экранировался дважды.

## 4.0.1 — 2026-10-25

Устойчивость к некорректным ответам устройств.

### Исправлено

- битый JSON от устройства не включает `online` и не пишет предупреждения PHP;
- ошибка создания UDP-сокета выбрасывает исключение вместо `die()` и не убивает страницу или цикл;
- шаг цикла ограничен 5 секундами, чтобы длинная очередь не сбивала heartbeat.

## 4.0.0 — 2026-10-25

Переписан интерфейс и цикл, движок устройств сохранён. Обновление ставится
поверх 3.2b без потери данных.

### Добавлено

- новый интерфейс на `MDJUI`: список, карточка устройства, свойства, привязки,
  настройки, токены, справка;
- чистые адреса `/panel/xiaomimiio/...` и вкладки `/panel/xiaomimiio/<id>/data.html`;
- каталог моделей с названиями, подписями и единицами свойств (`Catalog.php`);
- диагностика: `miIO.info`, произвольный метод, ответ устройства, очередь;
- backoff опроса после трёх ошибок и разброс интервала;
- колонки `FAILURES` и `LAST_SEEN` с автоматической миграцией;
- импорт вывода `token_extractor.py` без передачи пароля на сервер;
- ИК-обучение и LAN-режим шлюза через AJAX с CSRF;
- список, сопряжение и отвязка Zigbee-устройств шлюза;
- документация модуля для «Базы знаний» и статья о заимствованиях из Home Assistant.

### Изменено

- цикл `scripts/cycle_xiaomimiio.php` вызывает `cycleTick()` и обрабатывает
  ответы в своём процессе, без HTTP-запроса к `ajax/xiaomimiio.html`;
- настройки проверяются, сохраняются и перезапускают цикл;
- удалены `sleep()` из запроса статуса и отправка отложенных команд раньше времени;
- `miio.class.php` подключает `mipacket.class.php` относительно файла, а не CWD;
- модуль использует `Core::database()` для новых запросов и `addLinkedProperty()`
  для привязок;
- интерфейс и подписи — русские, как остальная админка; языковые файлы модуля
  и старые `.html`-шаблоны удалены.

### Удалено

- серверный запуск `token_extractor.py` с логином и паролем из формы;
- AJAX-операции `process`, `broadcast_search`, `get_miio_info`, `test_api_cmd`,
  `prop_update`, `single_prop_update`;
- Bootstrap 3, `bootstrap-select`, `usual.css`, `action_usual.html`;
- неиспользуемые языковые файлы `languages/xiaomimiio_*.php`.

### Исправлено

- падение при отсутствии таблицы `cached_cycles` (страница открывается, статус
  цикла показывается как неизвестный);
- неверный IP привязки сокета при поиске устройств (использовалась не та переменная);
- условие для `roborock.vacuum.m1s` ссылалось на несуществующую переменную;
- `callAPI` читает параметр `dopt`, а не только `opt`;
- фильтр привязок сравнивает объект и свойство точно, а не через `LIKE`.

### Обновление

Данные `miio_devices`, `miio_commands`, `miio_queue` и привязки сохраняются.
Новые колонки добавляются при первом открытии. Старый файл цикла нужно заменить.
Подробности: `modules/xiaomimiio/docs/upgrade.md`.
