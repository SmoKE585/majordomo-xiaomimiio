# Шлюзы Aqara

Дополнительные вкладки появляются у моделей `lumi.gateway.v3`
(Mi Smart Home Gateway 2) и `lumi.acpartner.v3` (Aqara AC Companion Gateway).

## Радио

Вкладка «Радио» показывает свойства:

- `all_program` — список станций (JSON);
- `current_program`, `current_status`, `current_progress`, `current_volume`;
- `add_program`, `del_program` — служебные строки для команд.

Их можно привязать к свойствам объекта как обычные метрики. Значения
обновляются по опросу, отдельного push-события у шлюза нет.

## Zigbee

Вкладка «Zigbee» запрашивает у шлюза список суб-устройств
(`get_device_prop` → `["lumi.0","device_list"]`) и показывает модель, статус и
кнопку отвязки.

- **Загрузить список** — повторный запрос.
- **Разрешить сопряжение (60 с)** — шлюз открывает окно присоединения.
  Переведите устройство в режим подключения в течение минуты.
- **Отвязать** — команда `remove_device`.

После сопряжения устройство появится в Mi Home и в списке шлюза. Сам модуль
не создаёт для суб-устройств отдельные объекты MajorDoMo — для этого
используйте модуль Zigbee2MQTT, если суб-устройства нужны как отдельные
сущности.

## LAN-режим

LAN-ключ (`lumi_dpf_aes_key`) нужен сторонним интеграциям шлюза. Кнопка
«Включить» генерирует новый ключ и отправляет его шлюзу, «Выключить» —
очищает. Текущий ключ показан рядом.

Это меняет настройки шлюза. Если сторонние интеграции не используются,
оставьте LAN-режим выключенным.

## ИК-обучение

Доступно для `lumi.acpartner.v3` и `chuangmi.ir.v2`:

1. Нажмите «Начать обучение».
2. Наведите пульт на устройство и нажмите нужную кнопку.
3. Дождитесь кода в журнале обучения.

Полученный код передаётся в команду `ir_play` (для Aqara — вместе с параметрами
пульта). Обучение идёт в фоне через AJAX-запросы с CSRF-токеном; страницу можно
не перезагружать.
