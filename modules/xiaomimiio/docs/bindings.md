# Свойства и привязки

## Таблица свойств

Каждая строка `miio_commands` — одно свойство или команда устройства:

- `TITLE` — ключ miIO (`power`, `bright`, `temp_dec`, `online`, …);
- `VALUE` — последнее известное значение;
- `UPDATED` — когда оно обновилось;
- `LINKED_OBJECT`, `LINKED_PROPERTY`, `LINKED_METHOD` — привязка к MajorDoMo.

Служебные строки создаются автоматически:

- `online` — 1/0, доступность;
- `message` — последний сырой ответ устройства (удобно для разбора);
- `command` — «выполнить произвольный метод»: значение этого свойства
  отправляется как имя метода miIO.

Остальные строки появляются после первого ответа устройства на запрос
состояния. Если свойств нет, нажмите «Опросить» на вкладке «Обзор».

## Привязка

1. Откройте свойство в таблице.
2. Выберите объект, свойство объекта и, при необходимости, метод.
3. Сохраните.

Когда устройство присылает новое значение, модуль записывает его в свойство
объекта. Когда свойство объекта меняется из сценария, панели или другого
модуля, модуль ставит команду устройству в очередь. Повтор того же значения
команду не отправляет — сравнение идёт по последнему значению строки.

Метод вызывается после записи свойства и получает параметры `PROPERTY`,
`VALUE`, `OLD_VALUE`, `NEW_VALUE`. Это удобно, если нужна реакция без
`ONCHANGE` у свойства.

## Чего избегать

Не пишите в `propertySetHandle` то же свойство, которое вызвало обработчик:
MajorDoMo остановит цепочку как зацикленную. Если нужно подтверждение
состояния, пишите его в отдельное свойство или в свойство устройства.

Также не стоит привязывать к одному свойству объекта несколько строк с разными
ключами: последняя запись победит, а команды будут конкурировать.

## Значения и единицы

Значения показываются как есть, но к известным числовым свойствам добавляются
единицы: `°C`, `%`, `ppm`, `Вт`, `В`. Подписи и единицы — только представление;
в объект и в команды уходит исходное значение miIO.

## Команды без привязки

Для разовых действий есть «Диагностика» → «Выполнить команду». Например:

- `get_prop` с параметрами `["power","bright"]`;
- `set_power` с параметрами `["on"]`;
- `get_status` для пылесоса;
- `miIO.info` для сведений об устройстве.

Команда выполняется сразу и не сохраняется. Для регулярных действий лучше
привязка или метод объекта, который вызывает `callAPI`.
