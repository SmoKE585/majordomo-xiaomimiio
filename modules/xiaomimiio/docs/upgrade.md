# Обновление с версии 3.x

Модуль ставится поверх прежней версии. **Данные не удаляются и не пересоздаются.**

## Данные

| Что | Что происходит |
| --- | --- |
| `miio_devices` | сохраняется; добавляются колонки `FAILURES`, `LAST_SEEN` |
| `miio_commands` | сохраняется полностью, включая значения и привязки |
| `miio_queue` | сохраняется; отложенные команды теперь соблюдают время `ADDED` |
| привязки объектов | сохраняются; `pvalues.LINKED_MODULES` не меняется |
| настройки модуля | читаются из `project_modules.DATA`, недостающие ключи берут значения по умолчанию |

Миграция колонок выполняется при первом открытии страницы или первом шаге цикла
(`ensureSchema()`). Пересоздания таблиц и потери связей нет.

## Что изменилось

- Интерфейс переведён на `MDJUI` (`md-*`), тёмную тему и ширину 390 px.
- Чистые адреса `/panel/xiaomimiio/...`; старые `?action=xiaomimiio&view_mode=...`
  открываются и ведут в те же разделы.
- Цикл `scripts/cycle_xiaomimiio.php` больше не вызывает `ajax/xiaomimiio.html`
  по HTTP: ответы устройств обрабатываются в том же процессе.
- Появился backoff опроса после трёх ошибок и разброс интервала.
- Прямые `sleep()` из запроса статуса убраны.
- Токены получаются вручную и импортируются текстом. Серверный запуск
  `token_extractor.py` с паролем удалён.
- Удалены встроенные Bootstrap 3, jQuery-плагины, `usual.css`, шаблоны `.html`
  и языковые файлы модуля. Тексты интерфейса — русские, как остальная админка.

## Совместимость API

`callAPI('/api/module/xiaomimiio','GET', array('did'=>…,'dcmd'=>…,'dopt'=>…))`
работает как раньше. В `dopt` передаётся JSON-массив параметров.

Внутренние AJAX-адреса прежней версии (`/ajax/xiaomimiio.html?op=process`,
`broadcast_search`, `get_miio_info`, `test_api_cmd`, `prop_update`,
`single_prop_update`) больше не поддерживаются: они принимали IP и токен из
query и не проверяли CSRF. Вместо них:

- очередь и ответы обрабатывает новый цикл;
- прямые команды — «Диагностика» в карточке устройства;
- многошаговые действия (ИК-обучение, Zigbee, LAN) — `/ajax/xiaomimiio.html`
  с `op`, `device_id` и CSRF-токеном.

Если вы обновляете только папку `modules/xiaomimiio` и оставили старый файл
цикла, замените и `scripts/cycle_xiaomimiio.php`.

## Что проверить после обновления

1. Откройте «Xiaomi miIO»: устройства и привязки на месте.
2. В карточке устройства нажмите «Опросить» — значения обновятся.
3. В X-Ray убедитесь, что `cycle_xiaomimiio` запущен.
4. Если токен был получен старым скриптом, он продолжает работать: менять его
   не нужно.
5. Для шлюзов проверьте вкладки «Радио» и «Zigbee»: они обращаются к тем же
   методам, что и раньше.

## Откат

Перед обновлением достаточно сделать резервную копию БД или экспорт модуля.
Откат на 3.2b потребует вернуть старые файлы шаблонов и цикла; данные таблиц
совместимы, новые колонки старой версии не мешают.
