# Токены

Токен — 32-символьный ключ, которым miIO шифрует обмен. Без него устройство
игнорирует запросы: UDP-пакет уходит, но ответа нет. Токен уникален для
устройства и не меняется при перезагрузке.

## Как получить

1. Скачайте `token_extractor.py` на странице «Токены» (файл лежит в
   `assets/modules/xiaomimiio/tools/token_extractor.py`).
2. На компьютере с Python 3 установите зависимость:
   `python3 -m pip install requests`.
3. Запустите скрипт, указав логин, пароль и регион:
   `python3 token_extractor.py --username ВАШ_ЛОГИН --password ВАШ_ПАРОЛЬ --server ru`.
   Регионы: `cn`, `de`, `us`, `ru`, `sg`, `in`, `i2`.
4. Скопируйте весь вывод. Для каждого устройства там будет блок `new-device`
   и строки `{IP}`, `{TOKEN}`, `{MODEL}`, `{NAME}`.
5. На странице «Токены» вставьте вывод в поле импорта и нажмите
   «Импортировать».

Импорт обновляет IP, токен, модель и название `New …` у совпавших по IP
устройств и добавляет отсутствующие. Существующие привязки не удаляются.

## Безопасность

- Пароль Xiaomi не отправляется в MajorDoMo: скрипт запускается на вашем
  компьютере, на сервер попадает только его текстовый вывод.
- В прежних версиях модуль запускал python на сервере с логином и паролем из
  формы. Этот способ удалён: он передавал пароль через веб-запрос и зависел от
  `exec()` на сервере.
- Токен хранится в таблице `miio_devices` и не выводится в журналы. В интерфейсе
  поле токена пустое: чтобы заменить, введите новый; чтобы оставить — не
  трогайте.

## Если скрипт не входит

- Включена двухфакторная проверка — скрипт может не получить токен. Возьмите
  токен из резервной копии Mi Home (Android) или из интеграции Home Assistant,
  где устройство уже добавлено.
- Неверный регион — переберите `ru`, `de`, `cn`, `us`.
- Xiaomi сменила вход — проверьте свежую версию `token_extractor.py` в проекте
  python-miio.

## Почему не через облако

Облачный вход дал бы автоматическое получение токенов и push-события, но
потребовал бы хранить пароль или refresh-токен аккаунта на сервере. В этой
версии выбран ручной токен: он не создаёт лишней точки отказа. Варианты
облачной авторизации и спецификации MIoT описаны в статье
[Что берём из Home Assistant](roadmap.md).
