# Xiaomi miIO — обзор

Модуль связывает MajorDoMo с Wi-Fi устройствами Xiaomi, Mijia, Yeelight,
Philips (Xiaomi) и шлюзами Aqara по локальному протоколу **miIO**: UDP-порт
54321, шифрование AES на ключе устройства (токене). Облако Xiaomi для работы
не нужно: IP и токен хранятся в таблице модуля, обмен идёт напрямую.

## Что есть в панели

| Раздел | Адрес | Назначение |
| --- | --- | --- |
| Устройства | `/panel/xiaomimiio.html` | список, поиск, состояние, быстрые действия |
| Новое устройство | `/panel/xiaomimiio/0/add.html` | IP, токен, модель, период опроса |
| Карточка устройства | `/panel/xiaomimiio/<id>.html` | обзор, диагностика, свойства, справка |
| Свойства | `/panel/xiaomimiio/<id>/data.html` | значения и привязки, поиск |
| Привязка свойства | `/panel/xiaomimiio/<id>/bind-<command>.html` | объект, свойство, метод |
| Радио шлюза | `/panel/xiaomimiio/<id>/gwradio.html` | станции и текущее воспроизведение |
| Zigbee шлюза | `/panel/xiaomimiio/<id>/gwzigbee.html` | сопряжение и отвязка суб-устройств |
| Настройки | `/panel/xiaomimiio/0/settings.html` | IP сокета, период поиска, таймаут, журналы |
| Токены | `/panel/xiaomimiio/0/tokens.html` | получение и импорт токенов |

Старые ссылки `?action=xiaomimiio&view_mode=...` продолжают открываться:
`edit_miio_devices`, `search_miio_devices`, `get_tokens`, `update_settings`,
`tab=data|gwradio|gwzigbee|help`.

## Как это работает

1. Цикл `cycle_xiaomimiio` раз в секунду забирает команды из `miio_queue` и
   отправляет их устройству по UDP.
2. Ответ разбирается движком устройства: значения раскладываются по строкам
   `miio_commands`, обновляется `online`, вызываются привязки объектов.
3. Раз в `UPDATE_PERIOD` секунд цикл опрашивает состояние устройства. Если оно
   не ответило три раза подряд, интервал автоматически замедляется (до 10 минут),
   чтобы не забивать сеть.
4. Периодически (по настройке) выполняется широковещательный поиск новых
   устройств: найденные записи появляются с названием `New …`.

## Совместимость и обновление

Таблицы `miio_devices`, `miio_commands`, `miio_queue` и все привязки сохранены
от версии 3.2b. При первом открытии модуль добавляет служебные колонки
`FAILURES` и `LAST_SEEN`, не пересоздавая таблицы. Подробности —
[Обновление с 3.x](upgrade.md).

## Ограничения

- Устройство должно быть доступно из сети MajorDoMo, а UDP 54321 — не закрыт
  файрволом.
- Для управления нужен токен. Как его получить — [Токены](tokens.md).
- ИК-обучение и LAN-режим шлюза работают только у моделей, которые это умеют:
  `lumi.acpartner.v3`, `chuangmi.ir.v2`, `lumi.gateway.v3`.
- Карта уборки пылесоса и BLE-устройства в этой версии не поддерживаются.
